- Property division: [Texas Family Code Chapter 7](https://statutes.capitol.texas.gov/?artSec=7.001&chapter=FA.7&code=FA&tab=1).

- Proportionate responsibility: [Chapter 33](https://tcss.legis.texas.gov/resources/CP/pdf/CP.33.pdf).
- Wrongful death beneficiaries: [Chapter 71](https://statutes.capitol.texas.gov/docs/cp/pdf/cp.71.pdf).
